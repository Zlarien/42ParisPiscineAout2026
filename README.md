# 42 Paris — Piscine Août 2026

Exercices réalisés pendant la piscine 42 Paris (août 2026), en C.

## Structure du dépôt

| Dossier | Thème |
|---|---|
| `C-00` à `C-XX` | Exercices C (pointeurs, strings, structures, etc.) |
| `C-Strings` | Manipulation de chaînes de caractères |
| `C-Structures` | Structures et tableaux de structures |
| `C-Memory-Management` | Allocation dynamique (`malloc`, `free`) |

## Compilation

Chaque exercice se compile individuellement avec `gcc` :

```sh
gcc -Wall -Wextra -Werror ex00/ft_*.c
./a.out
```

## Progression

- [x] C-Strings
- [x] C-Structures
- [x] C-Memory-Management

## Norme 42

Le code respecte la [Norme 42](https://github.com/42School/norminette) :
- en-tête 42 sur chaque fichier,
- fonctions limitées à 25 lignes,
- pas de `for`, pas de déclarations multiples par ligne.
